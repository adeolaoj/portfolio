  # Portfolio
  My website portfolio, deployed at adeolaojuade.com


  ## Running the code

  This project uses pnpm. From the `frontend` folder:

  Run `pnpm install` to install the dependencies.

  Run `pnpm dev` to start the development server.

  Run `pnpm build` to create a production build in `dist/` (Vercel runs this on deploy, so `dist/` is not committed).
